🚀 Horizon Bleu Logistique - Interactive Business Plan
----

🌟 Overview
----

This HTML file, index.html, is a single-page interactive web application that serves as a dynamic business plan for "Horizon Bleu Logistique," a proposed fish 🐟 transportation 🚚 company in Laâyoune, Morocco 🇲🇦.

Its primary purpose is to present a compelling and data-driven case for a loan application through the Moroccan government's "Intelaka" financing program 💰.

✨ Key Features & Sections
----

The application is structured as a professional, scrollable dashboard with the following sections:

🌍 Aperçu (Overview): High-level summary of the project and the total funding request.

📈 Marché (Market): Analysis of the market opportunity in Laâyoune, including a chart visualizing the price inflation in the seafood supply chain.

⚙️ Modèle Économique (Business Model): Details on the subcontracting model, value proposition, and role in the supply chain.

💸 Finances (Financials): The core interactive component. Users can:

Adjust the number of trucks and average monthly revenue per truck using sliders 🎛️.

Instantly see the impact on investment costs, operational costs, and projected monthly revenue, costs, and profit.

A dynamic bar chart visualizes these financial projections in real-time 📊.

👨‍💼 Fondateur (Founder): A profile outlining the founder's relevant experience.

📝 Demande de Prêt (Loan Request): A summary of the loan structure and the intended use of funds, based on the figures from the interactive financial planner.

🛠️ Technologies Used
----

HTML5: For the core structure and content.

Tailwind CSS: For modern, responsive styling 🎨.

JavaScript (Vanilla): To handle user interactions, update calculations, and manage the mobile menu 💡.

Chart.js: For creating the dynamic and responsive charts 📈.
